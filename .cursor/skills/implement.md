# 実装スキル（implement.md）

このスキルは、設計に基づいたコード実装の手順を定義します。

## 目的

課題管理表の設計サマリと設計内容に基づき、コードを実装する。

## 入力

- 課題管理表の設計サマリ
- 設計内容（基本設計・DB設計・画面設計・API/IF設計など）

## 処理

1. 設計内容を確認する
2. TODOリストを作成する（実装する項目・完了条件を明記）
3. コードを実装する
4. 実装内容をコミットする

## 出力

- 実装済みコード
- コミット（コミットメッセージは日本語で、変更内容がわかるように記述）

## 委譲

- このスキルは**サブエージェント（Composer 1.5）**に委譲して実行する
- 委譲時は設計サマリ・設計内容・関連ファイルのパスを渡す
