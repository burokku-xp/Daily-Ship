# テスト実行スキル（test.md）

このスキルは、実装済みコードに対するテスト実行の手順を定義します。

## 目的

実装済みコードに対してテストコードを作成し、テストを実行して結果をレポートする。

## 入力

- 実装済みコード
- テスト対象の範囲・仕様

## 処理

1. テスト計画を作成する
2. テストコードを作成する（単体テスト・結合テスト）
3. テストを実行する
4. テスト結果を記録する（成功/失敗、カバレッジ）
5. 失敗した場合は原因分析・修正・再テストを行う

## 出力

- テスト結果レポート
  - 成功/失敗の件数
  - カバレッジ情報
  - テストログ

## 委譲

- このスキルは**サブエージェント（Composer 1.5）**に委譲して実行する
- 委譲時は実装済みコードのパス・テスト対象の説明を渡す
