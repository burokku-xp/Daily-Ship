# Notion報告スキル

このスキルは、notionMCPを使用した結果報告の手順を定義します。

## 目的

テスト結果とVM検証結果をnotionMCPを使って結果報告DBに追加する。

## 入力

- テスト結果（成功/失敗、カバレッジ）
- VM検証結果（スクリーンショットへのリンク、動画へのリンク）
- 改修箇所情報（変更したファイル・モジュールの一覧）

## 処理

1. notionMCPを使用して結果報告DBに接続する
2. 新規ページを作成する
3. 以下の内容を記入する:
   - 報告タイトル: `[YYYY-MM-DD] {機能名} 実装結果報告`
   - 種別: 「テスト結果」
   - ステータス: 「レビュー中」
   - 報告日: 当日の日付
   - ページ本文:
     - 実装内容のサマリ
     - テスト結果（成功/失敗、カバレッジ）
     - VM検証結果（スクリーンショットへのリンク、動画へのリンク）
     - 改修箇所の一覧
     - 関連する設計ドキュメントへのリンク

## 出力

- 結果報告ページのURL

## 委譲

- このスキルは**サブエージェント（Composer 1.5）**に委譲して実行する
- 委譲時は入力情報をすべて渡す

## notionMCPの使い方（具体的な手順）

1. **MCP接続の確認**: notionMCPが設定されていることを確認する
2. **データベースの特定**: 結果報告DB（📊 結果報告）のデータベースIDを取得する
3. **ページ作成**: notionMCPの `createPage` または相当するAPIを使用してページを作成する
4. **プロパティ設定**: 種別・ステータス・報告日などのプロパティを設定する
5. **本文の記入**: ページ本文に上記の内容を記入する
6. **設計DBへのページ作成**: 該当する設計DB（基本設計・DB設計・画面設計など）に対応するページを新規作成し、改修箇所を明示する

## 結果報告DBへの追加手順（notion-create-pages）

**重要**: 結果報告DBに直接ページを追加するには、`parent` パラメータでDBを指定する。

### 結果報告DBのID
- データベースID: `a0a859b6-af41-4d8e-95c5-7b037390b2e3`

### notion-create-pages の呼び出し例

```
parent: {"type": "database_id", "database_id": "a0a859b6-af41-4d8e-95c5-7b037390b2e3"}
```

### プロパティ（properties）
- `報告タイトル`: タイトル（例: `[YYYY-MM-DD] {機能名} 実装結果報告`）
- `ステータス`: 「レビュー中」
- `種別`: 「テスト結果」「レビュー結果」「リリース報告」「その他」のいずれか
- `date:報告日:start`: 日付（YYYY-MM-DD形式）
- `date:報告日:is_datetime`: 0（日付のみの場合）

### 注意事項
- `parent` は**JSONオブジェクト**として渡す（文字列化しない）
- 親を省略すると通常ページとして作成され、DBには追加されない
